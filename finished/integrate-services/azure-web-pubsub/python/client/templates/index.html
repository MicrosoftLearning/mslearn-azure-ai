AI Investigation Updates - Azure Web PubSub

One investigation, two responders

A deterministic simulator investigates a fictional database connection incident. Azure Web PubSub delivers the updates; Azure Blob Storage retains the findings.

  1. Create a saved investigation. Both responder views connect automatically.
  2. Start the investigation as the on-call developer. Both views receive the same updates.
  3. Disconnect either view, let the other continue, then reconnect to recover the stored findings.

The responders are local demo roles, not separate sign-ins. Microsoft Entra ID authenticates the backend to Azure.
